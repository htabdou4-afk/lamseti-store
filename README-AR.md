# LAMSETI Production Starter (Free hosting + domain later)

هذه نسخة مشروع إنتاجي قابلة للنشر على Vercel مع Supabase كقاعدة بيانات ومصادقة وتخزين صور.
**ليست منشورة بعد**، وتحتاج إلى إنشاء مشروع Supabase وإضافة مفاتيحه ثم ربط GitHub بـ Vercel.

## محتويات المشروع
- `index.html`, `styles.css`, `app.js`: المتجر المتجاوب باللغة العربية.
- `assets/`: صور الدفاتر الأصلية المرفقة.
- `config.js`: إعداد اتصال Supabase (فارغ/placeholder حالياً).
- `config.example.js`: نموذج إعداد الاتصال.
- `supabase/schema.sql`: جداول المنتجات والطلبات والإعدادات، سياسات RLS، وسياسات تخزين الصور.
- `vercel.json`: إعداد نشر الموقع الثابت.

## 1) إنشاء قاعدة البيانات المجانية
1. أنشئ حساباً في https://supabase.com ثم مشروعاً جديداً.
2. اختر كلمة مرور قوية لقاعدة البيانات واحتفظ بها خارج ملفات الموقع.
3. افتح SQL Editor في مشروع Supabase.
4. انسخ محتوى `supabase/schema.sql` كاملاً وشغّله.
5. من Project Settings > API انسخ Project URL والمفتاح العام `anon` أو `publishable`.
6. افتح `config.js` وضع القيم مكان `YOUR-PROJECT` و`YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY`.
   - المفتاح العام anon/publishable مسموح في المتصفح مع RLS.
   - **ممنوع تماماً** وضع `service_role` أو أي secret key داخل `config.js` أو GitHub.

## 2) إنشاء حساب المالك بأمان
1. في Supabase افتح Authentication > Providers > Email، وتأكد من تفعيل Email.
2. من Authentication > Users أنشئ مستخدماً للمالك ببريدك وكلمة مرور قوية.
3. انسخ UUID الخاص بالمستخدم.
4. في SQL Editor شغّل الأمر التالي بعد استبدال UUID:
   ```sql
   insert into public.profiles (id, role)
   values ('ضع-UUID-هنا', 'admin')
   on conflict (id) do update set role = 'admin';
   ```
5. لا تفعّل التسجيل العام للمستخدمين، ولا تشارك بيانات دخول المالك.
6. سجّل الدخول من زر «دخول المالك» بالموقع. لن يسمح الموقع بالإدارة إلا لحساب موجود في `profiles` بدور admin.

## 3) النشر المجاني على Vercel
1. أنشئ حساب GitHub وحساب Vercel.
2. أنشئ مستودع GitHub جديداً وارفع محتويات هذا المجلد (لا ترفع أي service-role secret).
3. في Vercel اختر Add New > Project، ثم استورد المستودع.
4. Framework Preset: Other، وBuild Command وOutput Directory اتركهما فارغين/الافتراضي للموقع الثابت.
5. Deploy. سيعطيك Vercel رابطاً مجانياً على `vercel.app`.
6. جرّب الرابط من هاتف آخر وليس من جهازك فقط.

## 4) اختبار ما قبل استقبال الزبائن
- أضف منتجاً من لوحة المالك مع صورة وسعر.
- افتح الموقع في نافذة خاصة وتأكد أن المنتج والصورة ظاهران.
- نفّذ طلب سلة تجريبياً وطلب دفتر مخصص وطلب بطاقة أعمال.
- تحقق من وصول السجلات إلى جدول `orders` في Supabase.
- غيّر حالة الطلب من لوحة المالك.
- أضف رقم واتساب بصيغة دولية: الجزائر `213` ثم الرقم دون الصفر الأول، مثال شكلي `2135XXXXXXXX`.
- اختبر رابط واتساب على هاتف فعلي.
- اختبر عنوان التوصيل ورسومه يدوياً. النسخة الحالية تعرض ملاحظة التوصيل ولا تحسب أسعار شركات الشحن آلياً.

## وظائف النسخة
- كتالوج منتجات من قاعدة البيانات.
- إدارة المنتجات والأسعار والصور (رفع حتى 5MB للصورة).
- سلة وطلبات محفوظة مركزياً.
- طلب دفتر مخصص وطلب بطاقات أعمال مع الحقول التفصيلية.
- لوحة مالك محمية بمصادقة Supabase وصلاحية admin وسياسات RLS.
- تحديث واتساب ومعلومات المتجر من لوحة المالك.
- حالات الطلب: جديد، مؤكد، قيد الإنجاز، جاهز، تم الشحن، تم التسليم، ملغي.
- صور أولية محلية حتى يظهر التصميم قبل إعداد Supabase.

## ما لا تدّعيه هذه النسخة
- لا يوجد ربط API لشركة توصيل حتى الآن.
- لا يوجد دفع إلكتروني؛ الدفع والتأكيد يتمان بالتواصل مع الزبون.
- لم يتم نشر الموقع أو إعداد Supabase نيابة عنك لأن ذلك يتطلب حساباتك وموافقتك ومفاتيح مشروعك.
- رسوم التوصيل غير محسوبة تلقائياً؛ يتم تأكيدها يدوياً.
